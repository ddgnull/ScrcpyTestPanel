## 一、定位与版本规则

**定位**：macOS 平台 Android 自动化测试调度控制台 —— 多版本 scrcpy 投屏调度 + 独立 Appium 脚本调度 + HTML 报告快捷打开。

**版本关系**：工具**独立语义化版本**，与 scrcpy 版本无任何绑定或对应关系。scrcpy 只是被调度的外部二进制，可任意增删多版本。

| 项 | 规则 |
|---|---|
| 版本号 | `MAJOR.MINOR.PATCH`，首发 `0.0.1` |
| 递增 | PATCH=修复/微调，MINOR=新功能，MAJOR=破坏性变更 |
| Tag | `v0.0.1` |
| 发布形态 | **0.x 亦为正式版本**，不带 prerelease 标记，正常进入 Latest |
| 包名 | `ScrcpyTestPanel-v0.0.1-macos-aarch64.app.zip` |

**构建信息注入**：`scripts/gen_build_info.py` 生成 `_build_info.py`（不入库），`constants.py` 以 try/except 读取，缺失用兜底值。CI 与本地打包都必须先执行，保证两侧口径一致。

## 二、技术栈与约束

| 项 | 值 |
|---|---|
| 平台 | macOS aarch64 |
| Python | 3.14.7（用户现有环境，pyenv） |
| GUI | PySide6 6.10.3（**计划原为 6.7.2，因 Python 3.14 的 requires-python 限制改为 6.10.3**） |
| 打包 | PyInstaller 6.22.3 |
| UI | 纯代码，不使用 `.ui` 文件 |
| 外部依赖 | adb、scrcpy 二进制、测试脚本自身 venv（均不打包） |

**硬性约束**：
1. 所有外部进程用 **argv 列表** 启动，禁止 `shell=True`。
2. 一律 `start_new_session=True` + `killpg`，SIGTERM → 5s 宽限 → SIGKILL。
3. 子进程输出必须独立线程读取，禁止主线程阻塞读取。
4. 所有设备相关动作按 **serial** 反查，禁止用行号定位。
5. `--selftest` 必须在参数解析最早期分流，早于单实例锁与配置加载。

## 三、功能清单

### 3.1 设备管理
- QTimer 轮询 `adb devices`，默认 3000ms，配置 clamp 到 `[1000, 60000]`；F5 手动刷新。
- 列：状态｜序列号｜备注｜Scrcpy 版本｜投屏｜测试｜操作。
- 设备状态细分：`device` / `unauthorized` / `offline` / `no permissions` / `unknown`；非 `device` 状态操作置灰。
- 设备不可用时，自动终止该 SN 的投屏与测试，测试终态 `device_offline`。
- 重复序列号标红 + WARN。
- 表格按 serial **diff 增量刷新**，保留选中、编辑中的备注、下拉状态。
- 表头点击排序（按 serial 排序后重建，选择状态保留）。
- adb 异常捕获 + 设置页「重启 adb 服务」。

### 3.2 投屏调度
- 版本策略：设备绑定版本 > 全局默认版本。
- 启动前实时校验二进制（存在/可执行/`--version` 可返回）。
- 窗口标题统一 `STP-<serial>` 前缀，用于孤儿进程扫描。
- scrcpy 输出进入日志区（`[SCRCPY]`）。
- 手动关闭窗口后状态自动同步为「已退出」。
- 全局「全部断开投屏」二次确认；单设备启停不确认。

### 3.3 测试调度
- 任务模板：新增/编辑/删除/复制/启用停用。
- 保存校验：脚本存在、解释器可执行、`report_root` 可写、`task_id` 唯一、`timeout > 0`。
- 「连通性自检」：`interpreter -c` + `script --probe`。
- 启动前二次校验：设备在线、模板有效、单设备互斥。
- 6 种终态：`success` / `failed` / `timeout` / `stopped` / `device_offline` / `start_error`。
- 流式日志（`[TEST]`）；`REPORT_PATH` 取最后一次、支持跨块拼接、剥离 ANSI。
- 历史报告弹窗：报告被删除时条目置灰但保留记录。

### 3.4 日志
- 格式 `[时间] [来源] 内容`；来源 `[SYS]` / `[SCRCPY]` / `[TEST]`。
- 颜色：INFO 黑、WARN 黄、ERROR 红、测试失败红。
- 行数上限（默认 5000）+ 单行 2000 字符截断 + 150ms 批量刷新（防刷屏卡 UI）。
- 导出 txt、自动滚动开关、清空。
- 异常退出时保留最近 200 行日志落盘。

### 3.5 托盘与单实例
- 关闭窗口 → 隐藏到托盘（`QSystemTrayIcon`）。
- 托盘菜单：显示主窗口 / 全部断开投屏 / 终止全部测试 / 退出程序。
- 退出前确认并按需清理全部子进程。
- `QLockFile` + `QLocalServer` 单实例：重复启动提示并激活已有窗口。

### 3.6 配置
- 路径：`~/Library/Application Support/ScrcpyTestPanel/config.json`
- 原子写（临时文件 + `os.replace`）。
- `config_version` + 迁移函数表。
- JSON 损坏：备份 `config.broken.<ts>.json` 后重建默认。
- 加载期类型/范围校验，非法值回退默认。

## 四、`--selftest` 规范（必交付）

**定位**：无界面、无副作用、可重复执行的自检入口，用于 CI 门禁、打包后健康检查、用户排障。

**硬性禁止**：
1. 不创建 `QApplication`，不初始化任何 widget/tray。
2. 不开窗口、不联网、不读写用户真实配置目录。
3. 不启动任何外部进程（adb / scrcpy / 测试脚本）。
4. 文件操作限定在 `tempfile.mkdtemp()`，退出前清理。
5. 目标耗时 < 5s。

**12 项校验**：

| # | 内容 |
|---|---|
| 1 | 四个业务模块可导入 |
| 2 | PySide6 可导入（不实例化） |
| 3 | 版本三元组非空、非 `unknown` |
| 4 | 配置生成 → 原子写 → 重读一致 |
| 5 | 非法 JSON → 生成备份并重建默认 |
| 6 | 旧配置迁移：补齐字段、保留数据、clamp |
| 7 | `poll_interval` clamp（10→1000 / 999999→60000） |
| 8 | `timeout<=0` 回退默认；重复 `task_id` 被拒 |
| 9 | 目录段清洗（`../x`、`a/b`、控制字符） |
| 10 | 报告标记：跨块拼接、取最后一条、ANSI 剥离 |
| 11 | 退出码映射（0/1/130） |
| 12 | 设备 diff 纯函数（新增/移除/变更） |

**输出契约**：

```
SELFTEST BEGIN <version>
[1/12] import modules................ PASS  (4 modules)
...
SELFTEST OK
```

失败时最后一行为 `SELFTEST FAIL: <item>`，退出码 1；全部通过退出码 0。

## 八、发布（双轨）

### 8.1 本地手动（备选）
```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python scripts/gen_build_info.py --version 0.0.1
pyinstaller build_mac.spec --noconfirm
codesign --force --deep --sign - dist/ScrcpyTestPanel.app
ditto -c -k --keepParent dist/ScrcpyTestPanel.app ScrcpyTestPanel-v0.0.1-macos-aarch64.app.zip
shasum -a 256 ScrcpyTestPanel-v0.0.1-macos-aarch64.app.zip > SHA256SUMS.txt
```
手动上传 Release 时**直接 Publish，不勾 prerelease**。

### 8.2 GitHub Actions（主通道）
- **前提**：仓库不会开箱自动构建，必须把 `.github/workflows/` 提交到默认分支才生效。
- `ci.yml`：PR / push main → `compileall` + `--selftest`，不出包。
- `release-macos.yml`：推 `v*` tag 或 `workflow_dispatch` → 打包 + 签名 + 门禁 + zip + SHA256 + 正式 Release。
- Runner：`macos-15`（实测 `macos-14` 在本仓库会被**立即 cancelled 且不分配 runner**，`macos-13` 长期排队；`macos-15` 与 `ubuntu-latest` 正常）。
- 压缩必须 `ditto`，禁止 `zip`（会丢符号链接导致 .app 解压损坏）。
- 结论口径：推 tag 即自动构建并创建**正式 Release**（`prerelease=false`，正常进 Latest）。

**CI 九项门禁**：
1. `compileall` 通过
2. `--selftest` 通过（源码态）
3. 打包成功
4. `codesign --verify --deep --strict` 通过
5. `plutil -lint` 通过
6. `Contents/MacOS/ScrcpyTestPanel` 存在且可执行
7. `CFBundleShortVersionString` == tag 版本
8. 打包后二进制 `--selftest` 通过
9. zip 与 SHA256SUMS 同时上传

### 8.3 签名策略
V0.0.1 仅 ad-hoc 签名，不做 Apple 公证。用户首次打开需右键打开，或执行 `xattr -cr`。

| 编号 | 风险 | 处置 |

| R7 | 定时刷新丢选中/打断编辑 | serial diff 增量更新 |
| R8 | 排序后行号错位 | 一律按 serial 反查 |
| R9 | 路径含空格/中文/注入 | argv 列表 + `QUrl.fromLocalFile` + 目录段清洗 |
